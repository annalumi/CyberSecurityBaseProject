# A Project for HY Cyber Security Base

This is a simple Django-based application showing five security flaws and their fixes.

## Setup
1. Clone the repo
2. Create a virtual environment
3. Run `pip install -r requirements.txt`
4. Start the server with `python manage.py runserver`
